# Локальная настройка на Windows

## Инструменты и модели

- JDK 17 или новее, Maven и Node.js 22 или новее.
- Для локального запуска Nemotron нужен Java runtime с совместимой версией Microsoft C++ Runtime. Скрипт предпочитает `C:\Users\Public\NemotronTest\java-runtime\bin\java.exe`, если файл существует; другой `java.exe` можно указать через `-JavaExecutable`.
- Vosk: распакованная модель с `am/final.mdl`. Для локального демо используется компактная модель; путь задаётся `VOSK_MODEL_PATH` или `-VoskModelPath`.
- Nemotron runtime: `runtime/bin/nemo_speech_asr_c.dll`.
- Nemotron: `model.gguf`.
- CAM++: `speaker_embedding_model.onnx`.
- Для Whisper: Python-окружение с `faster-whisper`; путь задаётся `WHISPER_PYTHON` или `-WhisperPython`. Модель Whisper выбирается через `-WhisperModel`.

По умолчанию файлы моделей и Python-окружение ищутся в `C:\Users\Public\NemotronTest`. Не размещайте большие модели в синхронизируемом каталоге репозитория. Скрипт `download-model.ps1` скачивает полную Vosk-модель в `C:\Users\Public\NemotronTest\vosk-model-ru-0.42`; для другого пути передайте `-Destination`.

Whisper использует `stt-service/tools/whisper_server.py` на `127.0.0.1:9000`. Для проверки доставки PCM и уточнений без загрузки модели запускайте `scripts/run-local.ps1 -WhisperBackend fake`; это не проверяет качество Whisper. Если Python-окружение не подготовлено, запустите `scripts/run-local.ps1 -DisableWhisper`; в этом режиме оценки строятся по первичному тексту Vosk.

## Запуск

Из корня репозитория:

```powershell
.\scripts\run-local.ps1
```

Скрипт собирает и тестирует оба JAR, поднимает analytics на `127.0.0.1:8080`, helper Whisper на `127.0.0.1:9000` и интегрированный STT на `127.0.0.1:8765`. Он завершает дочерние процессы при остановке через `Ctrl+C`. Журналы запуска находятся в `%TEMP%\stt-diarization-service-logs`; файлы сессий — в `%PUBLIC%\NemotronTest\integrated-runs`.

Для ручного запуска:

```powershell
mvn -B test package
mvn -B -f stt-service/pom.xml test package
```

Затем задайте один и тот же `INTERVIEW_EVENTS_TOKEN` обоим процессам (не менее 32 символов), задайте `VOSK_MODEL_PATH` процессу STT и `WHISPER_URL=http://127.0.0.1:9000/transcribe`, если помощник включён. Сначала запустите analytics JAR с `--server.address=127.0.0.1`, затем STT JAR в режиме `integrated` с `--analytics-url ws://127.0.0.1:8080` и путями к трём файлам Nemotron/CAM++.

## Сценарий демо

1. Разрешите странице доступ к микрофону и системному звуку. Для системного звука выберите весь экран/вкладку и включите передачу звука.
2. Запишите эталон кандидата. Он используется CAM++ для идентификации роли.
3. Во время интервью браузер передаёт микрофон и системный звук. Наденьте наушники, чтобы речь из динамиков не возвращалась в микрофон.
4. Браузер автоматически озвучивает вопрос и отмечает начало ответа. Кнопки пропуска и завершения остаются доступны.
5. После завершения откройте ссылку XLSX в карточке отчёта. Полный путь результата также выводится в `output_dir`.

## Конфигурация и диагностика

Analytics слушает `8080`, STT HTTP API — `8765`, Whisper helper — `9000`. Все адреса локального сценария привязаны к loopback. При отдельном развёртывании двух сервисов перенесите внутренний канал на `wss`, передайте общий секрет через защищённую конфигурацию и откройте только необходимые порты.

Типичные причины отказа:

- **Модель не найдена:** проверьте `VOSK_MODEL_PATH` или `NEMOTRON_HOME`; файл должен быть доступен вне OneDrive и содержать перечисленные файлы.
- **Порт занят:** завершите предыдущий запуск трёх процессов.
- **401 при открытии WebSocket:** процессы получили разные значения `INTERVIEW_EVENTS_TOKEN` или секрет короче 32 символов.
- **Не удаётся подключиться к analytics:** проверьте `127.0.0.1:8080/healthz`, адрес `--analytics-url` и журнал процесса.
- **Очередь аудио переполнена:** проверьте нагрузку CPU, доступную память и наличие потерь при захвате аудио. Результаты указывают пропущенные интервалы.
- **Whisper недоступен:** проверьте Python-окружение и лог `whisper-helper`; интервью продолжится на тексте Vosk, если STT отправил `refine_done`.
- **Роль не определена:** улучшите качество записи эталона и уменьшите перекрытие интервьюера и кандидата.
